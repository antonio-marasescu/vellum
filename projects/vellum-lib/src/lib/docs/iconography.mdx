# Iconography

The library includes 67 carefully crafted icons covering common UI needs. All icons are:

- **Consistent sizing** — Available in 6 preset sizes (xs–xxl) or custom pixel values
- **Themeable** — Use color variants via the theme prop
- **Accessible** — Proper ARIA attributes for screen readers
- **Optimized** — Bundled as code, no HTTP requests
