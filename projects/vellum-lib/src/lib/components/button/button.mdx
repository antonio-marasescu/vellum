# Button

A standalone, unstyled-by-default `vlm-button`. Visual values come from the
`--vlm-button-*` CSS custom properties in `_button.tokens.css`; theme and size
are chosen via inputs.

## Fab

A round, icon-only button, in filled (`fab`) and outlined (`fab-outlined`) styles. The
`label` is still required for accessibility — it's rendered as the button's `aria-label`
instead of visible text.
