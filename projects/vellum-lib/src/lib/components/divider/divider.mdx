# Divider

A standalone, unstyled-by-default `vlm-divider`. It has no content of its own — the host
element only handles layout sizing, and an inner line element carries the actual visual
styling, driven by the `--vlm-divider-*` CSS custom properties in `_divider.tokens.css`.
