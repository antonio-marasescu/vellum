# Divider

A standalone, unstyled-by-default `vlm-divider`. It has no content of its own — the host
element only handles layout sizing, and an inner line element carries the actual visual
styling, driven by the `--vlm-divider-*` CSS custom properties in `_divider.tokens.css`.

## Theming

All visual aspects are controlled by CSS custom properties.

| Token                           | Description                           | Default                                    |
| ------------------------------- | ------------------------------------- | ------------------------------------------ |
| `--vlm-divider-width`           | Divider thickness                     | `1px`                                      |
| `--vlm-divider-inset-size`      | Inset from edges when `inset` is true | `16px`                                     |
| `--vlm-divider-neutral-color`   | Color for neutral theme               | Inherits from `--vlm-color-border`         |
| `--vlm-divider-primary-color`   | Color for primary theme               | Inherits from `--vlm-color-primary`        |
| `--vlm-divider-secondary-color` | Color for secondary theme             | Inherits from `--vlm-color-secondary-text` |
