# Checkbox

A standalone, unstyled-by-default `vlm-checkbox`. Visual values come from the
`--vlm-checkbox-*` CSS custom properties in `_checkbox.tokens.css`; theme and size are
chosen via inputs.

`vlm-checkbox` implements Angular's [`FormCheckboxControl`](https://angular.dev/api/forms/signals/FormCheckboxControl)
contract, so it can be bound directly with the `[field]` directive from
`@angular/forms/signals` — `disabled`, `invalid`, `errors`, `touched` and `required`
are kept in sync automatically, and blur is reported back via the `touch` output.
