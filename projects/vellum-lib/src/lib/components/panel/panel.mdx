# Panel

An expansion panel component that toggles content visibility. Similar to an accordion item, the panel displays a header that can be clicked to expand/collapse the body content.

## Usage

```html
<vlm-panel [(expanded)]="isExpanded">
  <span panelHeader>What is Vellum?</span>
  A personal Angular component library.
</vlm-panel>
```

## Content Projection

- **panelHeader**: Header content projected via `[panelHeader]` attribute
- **default**: Body content projected directly into the component

## Accessibility

- Uses `role="button"` on the header when not disabled
- Provides `aria-expanded` to indicate expansion state
- Supports keyboard interaction (Enter/Space) to toggle
- Links header and body via `aria-controls` when an `id` is provided
