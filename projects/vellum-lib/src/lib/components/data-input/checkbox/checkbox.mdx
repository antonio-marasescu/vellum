# Checkbox

A standalone, unstyled-by-default `vlm-checkbox`. Visual values come from the
`--vlm-checkbox-*` CSS custom properties in `_checkbox.tokens.css`; theme and size are
chosen via inputs.

`vlm-checkbox` implements Angular's [`FormCheckboxControl`](https://angular.dev/api/forms/signals/FormCheckboxControl)
contract, so it can be bound directly with the `[field]` directive from
`@angular/forms/signals` — `disabled`, `invalid`, `errors`, `touched` and `required`
are kept in sync automatically, and blur is reported back via the `touch` output.

## Theming

All visual aspects are controlled by CSS custom properties.

### Base Tokens

| Token                                | Description                    | Default |
| ------------------------------------ | ------------------------------ | ------- |
| `--vlm-checkbox-radius`              | Border radius                  | `4px`   |
| `--vlm-checkbox-font-weight`         | Label font weight              | `400`   |
| `--vlm-checkbox-transition-duration` | Transition duration            | `150ms` |
| `--vlm-checkbox-disabled-opacity`    | Opacity when disabled          | `0.5`   |
| `--vlm-checkbox-focus-ring-width`    | Focus ring width               | `2px`   |
| `--vlm-checkbox-gap`                 | Gap between checkbox and label | `8px`   |
| `--vlm-checkbox-border-width`        | Border width                   | `1px`   |

### Color Tokens

| Token                                   | Description                 |
| --------------------------------------- | --------------------------- |
| `--vlm-checkbox-label-color`            | Label text color            |
| `--vlm-checkbox-required-color`         | Required asterisk color     |
| `--vlm-checkbox-error-text-color`       | Error message color         |
| `--vlm-checkbox-error-font-size`        | Error message font size     |
| `--vlm-checkbox-unchecked-border-color` | Border color when unchecked |
| `--vlm-checkbox-unchecked-bg`           | Background when unchecked   |

### Theme Tokens

For each theme (`primary`, `secondary`, `error`):

- `--vlm-checkbox-{theme}-color` — Checked background color
- `--vlm-checkbox-{theme}-fg` — Checkmark color

### Size Tokens

Each size has tokens for box size and font size (xs, sm, md, lg, xl).
