# Toggle

A standalone, unstyled-by-default `vlm-toggle` — a switch-style boolean control (track

- sliding thumb), distinct from `vlm-checkbox`'s box-and-checkmark appearance. Visual
  values come from the `--vlm-toggle-*` CSS custom properties in `_toggle.tokens.css`;
  theme and size are chosen via inputs.

`vlm-toggle` implements Angular's [`FormCheckboxControl`](https://angular.dev/api/forms/signals/FormCheckboxControl)
contract, so it can be bound directly with the `[field]` directive from
`@angular/forms/signals` — `disabled`, `invalid`, `errors`, `touched` and `required`
are kept in sync automatically, and blur is reported back via the `touch` output.

## Theming

All visual aspects are controlled by CSS custom properties.

### Base Tokens

| Token                                 | Description                  | Default |
| ------------------------------------- | ---------------------------- | ------- |
| `--vlm-toggle-radius`                 | Border radius (pill-shaped)  | `999px` |
| `--vlm-toggle-font-weight`            | Label font weight            | `400`   |
| `--vlm-toggle-transition-duration`    | Transition duration          | `200ms` |
| `--vlm-toggle-thumb-transition-delay` | Thumb slide delay            | `40ms`  |
| `--vlm-toggle-disabled-opacity`       | Opacity when disabled        | `0.5`   |
| `--vlm-toggle-focus-ring-width`       | Focus ring width             | `2px`   |
| `--vlm-toggle-gap`                    | Gap between toggle and label | `8px`   |
| `--vlm-toggle-border-width`           | Border width                 | `1px`   |
| `--vlm-toggle-thumb-inset`            | Thumb inset from track edge  | `2px`   |

### Color Tokens

| Token                                 | Description               |
| ------------------------------------- | ------------------------- |
| `--vlm-toggle-label-color`            | Label text color          |
| `--vlm-toggle-required-color`         | Required asterisk color   |
| `--vlm-toggle-error-text-color`       | Error message color       |
| `--vlm-toggle-error-font-size`        | Error message font size   |
| `--vlm-toggle-unchecked-border-color` | Border color when off     |
| `--vlm-toggle-unchecked-bg`           | Track background when off |
| `--vlm-toggle-unchecked-thumb-color`  | Thumb color when off      |

### Theme Tokens

For each theme (`primary`, `secondary`, `error`):

- `--vlm-toggle-{theme}-color` — Track background when on
- `--vlm-toggle-{theme}-fg` — Thumb color when on

### Size Tokens

Each size (xs, sm, md, lg, xl) has tokens for track dimensions, thumb size, thumb travel distance, and font size.
