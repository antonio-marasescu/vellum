# Toast

A standalone, unstyled-by-default `vlm-toast`. Visual values come from the `--vlm-toast-*`
CSS custom properties in `_toast.tokens.css`; theme and variant are chosen via inputs.
Content is passed as `ng-content`. Renders with `role="status"` and `aria-live="polite"` so
assistive technology announces it when it appears.

Purely presentational — it does not manage its own visibility, positioning, or stacking.
Consumers are responsible for mounting/removing it (e.g. from a list of active
notifications) and reacting to the `removed` output.

## Theming

All visual aspects are controlled by CSS custom properties.

### Base Tokens

| Token                          | Description                     | Default                                              |
| ------------------------------ | ------------------------------- | ---------------------------------------------------- |
| `--vlm-toast-radius`           | Border radius                   | `8px`                                                |
| `--vlm-toast-font-weight`      | Font weight                     | `500`                                                |
| `--vlm-toast-font-size`        | Font size                       | `14px`                                               |
| `--vlm-toast-line-height`      | Line height                     | `1.4`                                                |
| `--vlm-toast-gap`              | Gap between elements            | `12px`                                               |
| `--vlm-toast-padding-block`    | Vertical padding                | `10px`                                               |
| `--vlm-toast-padding-inline`   | Horizontal padding              | `14px`                                               |
| `--vlm-toast-disabled-opacity` | Opacity when disabled           | `0.5`                                                |
| `--vlm-toast-shadow`           | Box shadow                      | `0 2px 8px color-mix(...)`                           |
| `--vlm-toast-remove-size`      | Remove button size              | `20px`                                               |
| `--vlm-toast-remove-icon-size` | Remove icon size                | `9px`                                                |
| `--vlm-toast-remove-hover-bg`  | Remove button hover background  | `color-mix(in oklch, currentColor 18%, transparent)` |
| `--vlm-toast-outlined-bg`      | Background for outlined variant | Inherits from `--vlm-color-bg`                       |

### Theme Color Tokens

For each theme (`primary`, `secondary`, `info`, `success`, `warning`):

- `--vlm-toast-{theme}-bg` — Background color (filled variant)
- `--vlm-toast-{theme}-fg` — Text color (filled variant)
- `--vlm-toast-{theme}-color` — Border/text color (outlined variant)
