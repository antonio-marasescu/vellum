# Swap Button

A standalone, unstyled-by-default `vlm-swap-button` — a round icon button that swaps
between two icons on click. Pass the two icons via the `swapOff` / `swapOn` attribute
slots; the transition is a crossfade + scale, not a full flip. `swapped` is a two-way
bindable model — `false` shows `swapOff`, `true` shows `swapOn` — so a consumer can also
read or drive which icon is active from outside (e.g. syncing with a `[data-theme]`
attribute for a light/dark toggle).

## Theming

All visual aspects are controlled by CSS custom properties.

### Base Tokens

| Token                                   | Description              | Default                                      |
| --------------------------------------- | ------------------------ | -------------------------------------------- |
| `--vlm-swap-button-radius`              | Border radius (circular) | `50%`                                        |
| `--vlm-swap-button-transition-duration` | Transition duration      | `150ms`                                      |
| `--vlm-swap-button-disabled-opacity`    | Opacity when disabled    | `0.5`                                        |
| `--vlm-swap-button-inactive-scale`      | Scale of inactive icon   | `0.6`                                        |
| `--vlm-swap-button-bg`                  | Background color         | `transparent`                                |
| `--vlm-swap-button-bg-hover`            | Background on hover      | Inherits from `--vlm-color-bg-surface-hover` |
| `--vlm-swap-button-color`               | Icon color               | Inherits from `--vlm-color-text`             |

### Size Tokens

Each size (xs, sm, md, lg, xl, xxl) has tokens for diameter and icon size.
