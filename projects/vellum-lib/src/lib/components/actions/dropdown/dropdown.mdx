# Dropdown

A standalone, unstyled-by-default `vlm-dropdown` — wraps `vlm-button` as its trigger
(forwarding `label`/`size`/`theme`/`variant`/`useIcon`/`preIcon`/`postIcon`) and opens a
menu of `items` on click, positioned with `@angular/cdk/overlay`. `items` is a list of
`{ key, value }` pairs — `value` is the label shown in the menu, `key` is what's emitted
by `selected` when a row is clicked.
