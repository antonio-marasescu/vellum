# Button Toggle Group

A standalone, unstyled-by-default `vlm-button-toggle-group` — a simplified equivalent of
Angular Material's `mat-button-toggle-group` (no ARIA pattern for now, just ids). Wrap
`vlm-button-toggle` children inside it; each toggle reads its `size`/`theme`/`disabled`
and selection state from this group via dependency injection, so those props only need
to be set once, on the group.

## Multiple selection

Setting `multiple` allows more than one toggle to be selected at once. `value` (and the
`selectionChange` output) are always a `string[]`, regardless of `multiple`. The output is
named `selectionChange` rather than `change` — Angular ESLint's `no-output-native` rule
forbids reusing native DOM event names for custom outputs.

## Theming

Group-level tokens control layout. Individual buttons inherit their styling from the button component tokens.

| Token                           | Description         | Default |
| ------------------------------- | ------------------- | ------- |
| `--vlm-button-toggle-group-gap` | Gap between buttons | `6px`   |
