# Avatar

A standalone, unstyled-by-default `vlm-avatar`. Renders an image when `useUrl` is true and
`url` is set, otherwise falls back to a text `placeholder` (e.g. initials). Visual values
come from the `--vlm-avatar-*` CSS custom properties in `_avatar.tokens.css`.

## Clickable

Setting `clickable` renders the avatar with a `button` role, keyboard interaction, and a
hover ring, and emits `clicked` when pressed.

## Theming

All visual aspects are controlled by CSS custom properties.

### Base Tokens

| Token                               | Description                     | Default                                          |
| ----------------------------------- | ------------------------------- | ------------------------------------------------ |
| `--vlm-avatar-radius`               | Border radius                   | `8px`                                            |
| `--vlm-avatar-font-weight`          | Font weight for initials        | `600`                                            |
| `--vlm-avatar-transition-duration`  | Transition duration             | `150ms`                                          |
| `--vlm-avatar-bg`                   | Background color                | Inherits from `--vlm-color-secondary`            |
| `--vlm-avatar-fg`                   | Text/initials color             | Inherits from `--vlm-color-secondary-foreground` |
| `--vlm-avatar-clickable-ring-width` | Focus ring width when clickable | `2px`                                            |
| `--vlm-avatar-clickable-ring-color` | Focus ring color                | Inherits from `--vlm-color-primary`              |

### Size Tokens

Each size (xs, sm, md, lg, xl, xxl) has tokens for diameter and font size.
