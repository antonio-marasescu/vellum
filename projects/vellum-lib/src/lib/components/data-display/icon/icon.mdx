## Theming

Icon size is controlled by CSS custom properties. Colors inherit from the current text color or can be set via theme.

### Size Tokens

| Token                 | Default |
| --------------------- | ------- |
| `--vlm-icon-size-xs`  | `16px`  |
| `--vlm-icon-size-sm`  | `18px`  |
| `--vlm-icon-size-md`  | `20px`  |
| `--vlm-icon-size-lg`  | `24px`  |
| `--vlm-icon-size-xl`  | `28px`  |
| `--vlm-icon-size-xxl` | `32px`  |

Color is controlled by the `theme` input or inherited from the parent's text color.
